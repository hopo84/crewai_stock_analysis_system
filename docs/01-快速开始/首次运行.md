# 首次运行

完成环境配置后，让我们运行第一个股票分析来验证系统是否正常工作。

## 运行前检查

### 1. 确认环境就绪

```bash
# 激活虚拟环境（如使用）
source .venv/bin/activate  # macOS/Linux
# 或
.venv\Scripts\activate     # Windows

# 检查依赖
python main.py --check-env
```

### 2. 验证配置文件

```bash
# 检查.env文件存在
ls -la .env

# 验证必需变量（不会显示具体值）
python -c "
import os
from dotenv import load_dotenv
load_dotenv()
required = ['OPENAI_API_KEY']
missing = [k for k in required if not os.getenv(k)]
if missing:
    print('❌ 缺少环境变量:', missing)
else:
    print('✅ 环境变量配置完整')
"
```

## 基础使用方式

### 方式1：命令行参数（推荐新手）

```bash
# 分析单只股票 - 美股示例
python main.py --company "苹果公司" --ticker "AAPL"

# 分析单只股票 - A股示例
python main.py --company "中国平安" --ticker "000001"

# 查看所有可用选项
python main.py --help
```

### 方式2：交互式模式

```bash
# 启动交互式模式
python main.py --interactive

# 系统会提示输入：
# 请输入公司名称: 苹果公司
# 请输入股票代码: AAPL
# 是否使用缓存 (y/n): y
```

### 方式3：配置文件模式

```bash
# 使用预定义配置
python main.py --config config/analysis_config.yaml
```

## 常见场景

### 1. 快速评估场景

```bash
# 快速分析（使用缓存，减少API调用）
python main.py --company "比亚迪" --ticker "002594" --quick

# 预计执行时间：2-3分钟
```

### 2. 深度分析场景

```bash
# 全面分析（禁用缓存，获取最新数据）
python main.py --company "茅台" --ticker "600519" --no-cache --detailed

# 预计执行时间：8-10分钟
```

### 3. 批量分析场景

```bash
# 批量分析多只股票
python main.py --batch config/stock_list.txt

# stock_list.txt 格式：
# 苹果公司,AAPL
# 微软,MSFT
# 谷歌,GOOGL
```

## 结果验证

### 1. 检查报告完整性


- ✅ 明确的投资建议（买入/卖出/持有）

```bash

```
