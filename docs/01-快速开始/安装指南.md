# 安装指南

本文档将指导您完成CrewAI股票分析系统的环境搭建和依赖安装。

## 系统要求

### 硬件要求
- 内存：至少 4GB RAM（推荐 8GB 以上）
- 存储：至少 2GB 可用空间
- 网络：稳定的互联网连接（用于获取市场数据）

### 软件要求
- **Python 3.9+**（推荐 3.10 或 3.11）
- **Git**（用于代码管理）
- **pip**（Python包管理器）

## 安装步骤

### 1. 检查Python环境

```bash
# 检查Python版本
python --version
# 或
python3 --version

# 检查pip版本
pip --version
# 或
pip3 --version
```

如果Python版本低于3.9，请先升级Python。

### 2. 克隆项目

```bash
# 克隆项目到本地
git clone [项目地址]
cd crewai_stock_analysis_system
```

### 3. 创建虚拟环境（推荐）

```bash
# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate
```

### 4. 安装依赖

```bash
# 升级pip到最新版本
pip install --upgrade pip

# 安装项目依赖
pip install -r requirements.txt
```

### 5. 验证安装

```bash
# 运行系统检查
python main.py --check-env
```

如果看到"环境检查通过"的消息，说明安装成功。

## 常见安装问题

### 问题1：pip安装超时

**解决方案**：使用国内镜像源
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/
```

### 问题2：依赖冲突

**解决方案**：清理环境重新安装
```bash
pip uninstall -r requirements.txt -y
pip install -r requirements.txt
```

### 问题3：权限错误

**解决方案**：使用用户级安装
```bash
pip install --user -r requirements.txt
```

### 问题4：特定包安装失败

**解决方案**：单独安装问题包
```bash
# 例如akshare安装失败
pip install akshare --no-cache-dir
```
