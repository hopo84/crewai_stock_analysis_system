## 安装和环境问题

### 问题1：Python版本不兼容

**错误信息**：
```
ERROR: This package requires Python '>=3.9.0'
```

**解决方案**：
```bash
# 检查Python版本
python --version

# 如果版本过低，安装Python 3.9+
# macOS (使用Homebrew)
brew install python@3.11

# Ubuntu/Debian
sudo apt update && sudo apt install python3.11

# 重新创建虚拟环境
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 问题2：依赖包冲突

**错误信息**：
```
ERROR: pip's dependency resolver does not currently consider all the packages that are installed
```

**解决方案**：
```bash
# 方案1：清理并重新安装
pip uninstall -r requirements.txt -y
pip install -r requirements.txt

# 方案2：使用虚拟环境隔离
rm -rf .venv
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 方案3：逐个安装核心依赖
pip install crewai crewai-tools openai python-dotenv
pip install pandas numpy akshare
pip install -r requirements.txt
```

### 问题3：网络连接问题

**错误信息**：
```
ReadTimeoutError: HTTPSConnectionPool
```

**解决方案**：
```bash
# 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/

# 增加超时时间
pip install --timeout 1000 -r requirements.txt

# 配置代理（如需要）
export HTTP_PROXY=http://your-proxy:port
export HTTPS_PROXY=https://your-proxy:port
```

## API密钥和认证问题

### 问题4：OpenAI API密钥无效

**错误信息**：
```
openai.AuthenticationError: Incorrect API key provided
```

**解决方案**：

1. **检查密钥格式**：
```bash
# 密钥应以sk-开头，长度约51字符
echo $OPENAI_API_KEY | wc -c
```

2. **验证密钥有效性**：
```bash
curl https://api.openai.com/v1/models \
  -H "Authorization: Bearer $OPENAI_API_KEY" | head -20
```

3. **重新生成密钥**：
- 访问 [OpenAI API Keys](https://platform.openai.com/api-keys)
- 删除旧密钥，创建新密钥
- 更新.env文件

### 问题5：API配额不足

**错误信息**：
```
openai.RateLimitError: You exceeded your current quota
```

**解决方案**：

1. **检查账户余额**：
   - 访问 [OpenAI账单页面](https://platform.openai.com/account/billing)
   - 查看使用情况和剩余额度

2. **配置使用限制**：
```env
# 在.env中添加
MAX_TOKENS_PER_REQUEST=1000
REQUEST_INTERVAL=2  # 请求间隔秒数
```

3. **使用更便宜的模型**：
```env
# 改用GPT-3.5-turbo
OPENAI_MODEL=gpt-3.5-turbo
```

### 问题6：API请求频率限制

**错误信息**：
```
openai.RateLimitError: Rate limit reached
```

**解决方案**：
```python
# 在代码中添加重试机制（系统已内置）
# 或调整配置
REQUEST_RETRY_TIMES=3
REQUEST_RETRY_DELAY=5
```

## 数据获取问题

### 问题7：股票数据获取失败

**错误信息**：
```
Exception: Failed to fetch stock data for AAPL
```

**解决方案**：

1. **检查股票代码格式**：
```bash
# A股：6位数字（如：000001）
# 美股：字母代码（如：AAPL）
# 港股：5位数字（如：00700）
```

2. **验证数据源连接**：
```bash
python -c "
import akshare as ak
try:
    data = ak.stock_zh_a_spot_em()
    print('✅ AKShare连接正常')
except Exception as e:
    print('❌ AKShare连接失败:', e)
"
```

3. **使用备用数据源**：
```env
# 配置多个数据源
PRIMARY_DATA_SOURCE=akshare
BACKUP_DATA_SOURCE=tushare
```

### 问题8：网络搜索功能失败

**错误信息**：
```
SerperDevTool error: API key not found
```

**解决方案**：
```env
# 在.env中添加Serper API密钥（可选）
SERPER_API_KEY=your-serper-key

# 或禁用搜索功能
ENABLE_WEB_SEARCH=false
```

## 执行和性能问题

### 问题9：分析执行超时

**错误信息**：
```
TimeoutError: Analysis took longer than 600 seconds
```

**解决方案**：

1. **增加超时时间**：
```env
ANALYSIS_TIMEOUT=1200  # 20分钟
TASK_TIMEOUT=600      # 10分钟
```

2. **优化模型配置**：
```env
# 减少token使用
MAX_TOKENS_PER_TASK=800
MODEL_TEMPERATURE=0.3

# 使用更快的模型
OPENAI_MODEL=gpt-3.5-turbo
```

3. **启用缓存**：
```bash
python main.py --company "苹果" --ticker "AAPL" --use-cache
```

### 问题10：内存使用过高

**解决方案**：
```env
# 限制并发任务数
MAX_CONCURRENT_AGENTS=2

# 启用垃圾回收
ENABLE_MEMORY_CLEANUP=true

# 使用流式处理
STREAM_RESPONSES=true
```

### 问题11：分析结果不准确

**原因分析和解决方案**：

1. **数据过时**：
```bash
# 禁用缓存获取最新数据
python main.py --no-cache --company "公司名" --ticker "代码"
```

2. **模型配置问题**：
```env
# 提高创造性
MODEL_TEMPERATURE=0.7

# 使用更强大的模型
OPENAI_MODEL=gpt-4o
```

3. **提示词优化**：
- 检查 `config/agents.yaml` 和 `config/tasks.yaml`
- 确保角色描述清晰准确

## 报告生成问题

### 问题12：报告文件未生成

**解决方案**：

1. **检查输出目录权限**：
```bash
# 确保有写入权限
chmod 755 ./
ls -la *.md
```

2. **检查磁盘空间**：
```bash
df -h .
```

3. **手动指定输出路径**：
```bash
python main.py --output-dir ./reports --company "公司名" --ticker "代码"
```

### 问题13：报告格式错乱

**解决方案**：
```env
# 强制使用UTF-8编码
REPORT_ENCODING=utf-8

# 统一换行符
REPORT_LINE_ENDING=\n
```

### 应急措施

如果系统完全无法运行：

```bash
# 重置环境
rm -rf .venv
rm .env
cp .env.example .env
# 重新配置API密钥

# 重新安装
python -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt

# 验证安装
python main.py --check-env
```

## 预防措施

为避免常见问题：

1. **定期更新依赖**：
```bash
pip install --upgrade -r requirements.txt
```

2. **监控API使用**：定期检查OpenAI账单

3. **备份配置**：保存 `.env` 文件副本（移除敏感信息）

4. **版本锁定**：在生产环境使用固定版本的依赖

5. **测试验证**：定期运行 `python main.py --check-env`

记住：大多数问题都有解决方案，耐心排查通常能找到根本原因。
