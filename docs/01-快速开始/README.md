# 快速开始

CrewAI股票分析系统是一个基于多智能体协作的股票分析平台，能够自动进行市场研究、财务分析和投资建议生成。

- [安装指南](./安装指南.md) - 环境搭建和依赖安装
- [环境配置](./环境配置.md) - API密钥和环境变量配置
- [首次运行](./首次运行.md) - 快速启动系统进行股票分析
- [故障排除](./故障排除.md) - 常见问题解决方案

## 系统概述

本系统采用CrewAI框架构建，包含以下核心组件：

### 智能体团队
- **市场研究分析师** - 收集市场数据和行业趋势
- **财务分析师** - 分析公司财务状况
- **技术分析师** - 进行技术指标分析
- **风险评估师** - 识别投资风险
- **投资顾问** - 综合分析提供投资建议

### 主要功能
- 单股票深度分析
- 批量股票对比分析
- 实时市场数据获取
- 多维度风险评估
- 自动化报告生成

## 快速体验

如果您想立即体验系统功能，可以按照以下步骤：

1. **环境准备**（5分钟）
   ```bash
   git clone [项目地址]
   cd crewai_stock_analysis_system
   pip install -r requirements.txt
   ```

2. **配置API密钥**（2分钟）
   ```bash
   cp .env.example .env
   # 编辑.env文件，添加您的OpenAI API密钥
   ```

3. **运行分析**（1分钟）
   ```bash
   python main.py --company "苹果公司" --ticker "AAPL"
   ```

详细步骤请参考各子文档。
