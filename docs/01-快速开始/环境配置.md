# 环境配置

完成基础安装后，您需要配置环境变量和API密钥以确保系统正常运行。

## 环境变量配置

### 1. 创建环境配置文件

```bash
# 复制示例配置文件
cp .env.example .env
```

### 2. 编辑配置文件

使用您喜欢的文本编辑器打开 `.env` 文件：

```bash
# 使用nano编辑器
nano .env

# 或使用vim
vim .env

# 或使用VS Code
code .env
```

### 3. 必需的环境变量

```env
# 模型提供商选择（openai 或 deepseek）
MODEL_PROVIDER=openai

# OpenAI API配置（当MODEL_PROVIDER=openai时必需）
OPENAI_API_KEY=sk-your-openai-api-key-here
OPENAI_CHAT_MODEL=gpt-4o-mini
OPENAI_MANAGER_MODEL=gpt-4o-mini
OPENAI_PLANNING_MODEL=gpt-4o-mini
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MAX_TOKENS=4000
OPENAI_TEMPERATURE=0.7

# DeepSeek API配置（当MODEL_PROVIDER=deepseek时必需）
DEEPSEEK_API_KEY=sk-your-deepseek-api-key-here
DEEPSEEK_CHAT_MODEL=deepseek-chat
DEEPSEEK_CODER_MODEL=deepseek-coder
DEEPSEEK_MANAGER_MODEL=deepseek-chat
DEEPSEEK_PLANNING_MODEL=deepseek-chat
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_MAX_TOKENS=4000
DEEPSEEK_TEMPERATURE=0.7
DEEPSEEK_TOP_P=0.95

# 日志级别配置
LOG_LEVEL=INFO

# 系统配置
USE_CACHE=true
CACHE_DURATION=3600  # 缓存时间（秒）
```

### 4. 可选的环境变量

```env
# Web搜索API（提升数据获取能力）
SERPER_API_KEY=your-serper-api-key-here

# 数据库配置（如需要持久化存储）
```

## API密钥获取

### OpenAI API密钥

1. **注册OpenAI账户**
   - 访问 [OpenAI官网](https://platform.openai.com/)
   - 注册或登录账户

2. **创建API密钥**
   - 进入 [API Keys页面](https://platform.openai.com/api-keys)
   - 点击"Create new secret key"
   - 复制生成的密钥（以 `sk-` 开头）

3. **配置计费**
   - 访问 [计费页面](https://platform.openai.com/account/billing)
   - 添加付款方式
   - 设置使用限额

**注意事项**：
- API密钥只显示一次，请妥善保存
- 建议设置使用限额防止意外消费
- GPT-4模型效果更好但成本较高，GPT-3.5-turbo性价比更高

### DeepSeek API密钥

1. **注册DeepSeek账户**
   - 访问 [DeepSeek官网](https://platform.deepseek.com/)
   - 注册或登录账户

2. **创建API密钥**
   - 进入API密钥管理页面
   - 创建新的API密钥
   - 复制生成的密钥（通常以 `sk-` 开头）

3. **配置额度**
   - 查看账户余额和使用限额
   - 根据需要充值或设置使用限制

**DeepSeek优势**：
- 成本更低，性价比高
- 优秀的中文支持能力
- 专门的代码生成模型（deepseek-coder）
- 兼容OpenAI API接口标准

### Serper API密钥（可选）

如需增强网络搜索能力：

1. 访问 [Serper.dev](https://serper.dev/)
2. 注册账户并获取免费API密钥
3. 每月免费2500次搜索请求

## 安全建议

### 1. 保护API密钥

- ❌ **不要**将 `.env` 文件提交到版本控制系统
- ❌ **不要**在代码中硬编码API密钥
- ✅ 使用环境变量存储敏感信息
- ✅ 定期轮换API密钥

### 2. 权限最小化

```env
# 限制OpenAI使用额度
OPENAI_MAX_TOKENS=2000
OPENAI_TEMPERATURE=0.7

# 启用请求限制
RATE_LIMIT_ENABLED=true
MAX_REQUESTS_PER_HOUR=100
```

### 3. 备份配置

```bash
# 创建配置备份（移除敏感信息）
cp .env .env.backup
# 手动移除API密钥后保存
```

## 故障排除

### 问题：API密钥无效

**检查步骤**：
```bash
# 检查当前模型提供商
echo $MODEL_PROVIDER

# 检查对应的API密钥
echo $OPENAI_API_KEY    # 如果使用OpenAI
echo $DEEPSEEK_API_KEY  # 如果使用DeepSeek
```

**解决方案**：
- 确认密钥格式正确（通常以 `sk-` 开头）
- 检查账户余额是否充足
- 验证API密钥权限
- 确认MODEL_PROVIDER设置正确

### 问题：网络连接失败

**解决方案**：
```env
# 配置代理（如需要）
HTTP_PROXY=http://your-proxy:port
HTTPS_PROXY=https://your-proxy:port

# 或配置API代理
OPENAI_BASE_URL=https://your-openai-proxy.com/v1      # OpenAI代理
DEEPSEEK_BASE_URL=https://your-deepseek-proxy.com/v1  # DeepSeek代理
```

### 问题：数据获取失败

**检查步骤**：
```bash
# 测试网络连接
curl -I https://www.baidu.com

# 测试股票数据源
python -c "import akshare as ak; print(ak.tool_trade_date_hist_sina()[-5:])"
```
