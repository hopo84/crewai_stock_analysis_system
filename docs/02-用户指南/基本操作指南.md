# 基本操作指南

本文档详细介绍CrewAI股票分析系统的日常操作方法，帮助用户快速掌握系统使用技巧。

## 基础操作流程

### 1. 系统启动前检查

```bash
# 检查环境是否就绪
python main.py --check-env

# 确认API密钥配置
python main.py --verify-api

# 查看系统状态
python main.py --status
```

### 2. 单股票分析操作

#### 标准分析流程
```bash
# 基本语法
python main.py --company "公司名称" --ticker "股票代码"

# A股示例
python main.py --company "中国平安" --ticker "000001"

# 美股示例
python main.py --company "苹果公司" --ticker "AAPL"

# 港股示例
python main.py --company "腾讯控股" --ticker "00700"
```

#### 指定分析模式
```bash
# 快速分析（2-3分钟）
python main.py --company "比亚迪" --ticker "002594" --quick

# 标准分析（5-7分钟，默认）
python main.py --company "茅台" --ticker "600519"

# 深度分析（10-15分钟）
python main.py --company "宁德时代" --ticker "300750" --detailed
```

#### 输出控制选项
```bash
# 指定输出目录
python main.py --company "公司名" --ticker "代码" --output-dir ./reports

# 指定报告文件名
python main.py --company "公司名" --ticker "代码" --output-name "custom_report"

# 启用详细输出
python main.py --company "公司名" --ticker "代码" --verbose

# 静默模式（仅关键信息）
python main.py --company "公司名" --ticker "代码" --quiet
```

### 3. 批量分析操作

#### 创建股票列表文件
```bash
# 创建stocks.txt文件
cat > stocks.txt << EOF
中国平安,000001
茅台,600519
比亚迪,002594
宁德时代,300750
EOF
```

#### 执行批量分析
```bash
# 基础批量分析
python main.py --batch stocks.txt

# 批量快速分析
python main.py --batch stocks.txt --quick

# 并发批量分析（提高效率）
python main.py --batch stocks.txt --concurrent 3

# 批量分析并生成对比报告
python main.py --batch stocks.txt --compare
```

## 常用操作示例


## 参数配置详解

### 基础参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `--company` | 公司名称 | `--company "苹果公司"` |
| `--ticker` | 股票代码 | `--ticker "AAPL"` |
| `--quick` | 快速分析模式 | `--quick` |
| `--detailed` | 深度分析模式 | `--detailed` |

### 输出控制参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `--output-dir` | 输出目录 | `--output-dir ./reports` |
| `--output-name` | 输出文件名前缀 | `--output-name "AAPL_analysis"` |
| `--format` | 输出格式 | `--format json` |
| `--save-charts` | 保存图表 | `--save-charts` |

### 数据控制参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `--use-cache` | 使用缓存数据 | `--use-cache` |
| `--no-cache` | 禁用缓存 | `--no-cache` |
| `--data-source` | 指定数据源 | `--data-source akshare` |
| `--start-date` | 分析起始日期 | `--start-date 2024-01-01` |

### 高级参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `--model` | 指定AI模型 | `--model gpt-4` |
| `--temperature` | 模型创造性 | `--temperature 0.3` |
| `--max-tokens` | 最大token数 | `--max-tokens 2000` |
| `--concurrent` | 并发任务数 | `--concurrent 3` |

## 结果查看和管理

### 查看分析结果

```bash
# 查看主报告
cat final_investment_analysis.md

# 查看特定部分
head -50 financial_analysis_report.md

# 在浏览器中查看（如支持Markdown）
open final_investment_analysis.md

# 转换为PDF（需要pandoc）
pandoc final_investment_analysis.md -o report.pdf
```

### 结果文件管理

```bash
# 查看生成的文件
ls -la *_report.md *.md

# 按日期组织文件
mkdir -p results/$(date +%Y%m%d)
mv *_report.md final_investment_analysis.md results/$(date +%Y%m%d)/

# 压缩存档
tar -czf analysis_$(date +%Y%m%d).tar.gz *_report.md *.md charts/
```

### 结果对比分析

```bash
# 对比不同时间的分析结果
diff old_report.md new_report.md

# 提取关键信息对比
grep -E "(投资建议|目标价|风险评级)" *.md

# 生成对比报告
python tools/compare_reports.py report1.md report2.md
```

## 配置文件使用

### 创建配置文件

```yaml
# config/my_analysis.yaml
analysis:
  mode: standard
  model: gpt-3.5-turbo
  temperature: 0.3
  use_cache: true

output:
  directory: ./results
  format: markdown
  save_charts: true

data:
  sources:
    - akshare
    - yahoo_finance
  period: 1year

agents:
  market_researcher:
    focus:
      - industry_analysis
      - news_sentiment

  financial_analyst:
    indicators:
      - ROE
      - PEG
      - debt_ratio
```

### 使用配置文件

```bash
# 使用自定义配置
python main.py --config config/my_analysis.yaml --company "公司名" --ticker "代码"

# 覆盖配置中的特定参数
python main.py --config config/my_analysis.yaml --model gpt-4 --company "公司名"
```

## 错误处理和恢复

### 常见错误处理

```bash
# 分析中断后恢复
python main.py --resume last_analysis.state

# 跳过失败的任务继续执行
python main.py --batch stocks.txt --skip-errors

# 重试失败的分析
python main.py --retry failed_analysis.log
```

### 调试模式

```bash
# 启用调试模式
python main.py --debug --company "公司名" --ticker "代码"

# 保存中间结果
python main.py --save-intermediate --company "公司名" --ticker "代码"

# 模拟模式（不调用API）
python main.py --simulate --company "公司名" --ticker "代码"
```
