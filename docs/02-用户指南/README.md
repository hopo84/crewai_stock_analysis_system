## 系统定位

CrewAI股票分析系统是一个**智能投资分析助手**，利用多智能体协作技术，为用户提供：

### 🎯 核心价值
- **全面分析**：从市场、财务、技术、风险多维度分析
- **智能协作**：多个专业AI助手协同工作
- **决策支持**：提供明确的投资建议和风险提示
- **时效性强**：实时获取最新市场数据和信息

### 👥 目标用户
- **个人投资者**：需要专业分析支持的散户投资者
- **投资顾问**：需要提高分析效率的专业人士
- **研究分析师**：需要快速生成研究报告的分析师
- **投资机构**：需要批量分析和监控的机构用户

## 使用场景

### 📊 日常投资决策
```bash
# 快速评估投资机会
python main.py --company "比亚迪" --ticker "002594" --quick
```

### 📈 深度投资研究
```bash
# 全面分析投资标的
python main.py --company "茅台" --ticker "600519" --detailed
```

### 🔄 投资组合管理
```bash
# 批量分析持仓股票
python main.py --batch portfolio.txt --compare
```

### ⚡ 热点追踪
```bash
# 分析市场热点
python main.py --trending --sector "新能源汽车"
```

## 快速上手

### 第一步：选择分析对象
```bash
# 分析A股
python main.py --company "中国平安" --ticker "000001"

# 分析美股
python main.py --company "苹果公司" --ticker "AAPL"

# 分析港股
python main.py --company "腾讯控股" --ticker "00700"
```

### 第二步：选择分析模式
```bash
# 快速分析（2-3分钟）
--quick

# 标准分析（5-7分钟）
# 默认模式，无需参数

# 深度分析（10-15分钟）
--detailed
```

### 第三步：查看分析结果
```bash
# 主报告
cat final_investment_analysis.md

# 子报告
ls *_report.md
```
