# 主要功能概述

CrewAI股票分析系统提供全面的股票投资分析功能，通过多智能体协作实现专业级的投资研究能力。

## 核心功能模块

### 1. 智能体协作分析

#### 🔍 市场研究功能
**负责智能体**: 市场研究分析师

**主要职能**:
- **实时数据获取**: 自动获取最新股价、成交量、市值等基础数据
- **行业分析**: 分析所属行业的发展趋势和竞争格局
- **新闻情报**: 收集和分析相关新闻、公告、研报等信息
- **宏观环境**: 评估宏观经济环境对投资标的的影响

**输出内容**:
```markdown
## 市场研究报告
- 基础数据概览
- 行业地位分析
- 市场情绪评估
- 重要事件影响
```

#### 💰 财务分析功能
**负责智能体**: 财务分析师

**主要职能**:
- **财务报表分析**: 解读资产负债表、利润表、现金流量表
- **关键指标计算**: 计算ROE、毛利率、负债率等财务指标
- **盈利能力评估**: 分析盈利质量和可持续性
- **财务健康度**: 评估偿债能力和经营效率

**输出内容**:
```markdown
## 财务分析报告
- 财务概况总结
- 盈利能力分析
- 财务健康度评估
- 同业对比分析
```

#### 📈 技术分析功能
**负责智能体**: 技术分析师

**主要职能**:
- **趋势分析**: 识别价格趋势和关键支撑阻力位
- **技术指标**: 计算和解读MA、MACD、RSI等技术指标
- **形态识别**: 识别常见的价格形态和交易信号
- **量价分析**: 分析成交量与价格的关系

**输出内容**:
```markdown
## 技术分析报告
- 趋势方向判断
- 关键技术指标
- 支撑阻力位
- 交易信号识别
```

#### ⚠️ 风险评估功能
**负责智能体**: 风险评估师

**主要职能**:
- **风险识别**: 识别各类投资风险因素
- **风险量化**: 计算VaR、Beta等风险指标
- **压力测试**: 模拟不同市场情况下的表现
- **风险控制**: 提供风险管理建议

**输出内容**:
```markdown
## 风险评估报告
- 主要风险因素
- 风险量化分析
- 风险控制建议
- 压力测试结果
```

#### 👨‍💼 投资决策功能
**负责智能体**: 投资顾问

**主要职能**:
- **综合评估**: 整合各项分析结果
- **投资建议**: 给出明确的买入/卖出/持有建议
- **目标价格**: 设定合理的价格目标
- **投资策略**: 制定具体的投资执行策略

**输出内容**:
```markdown
## 投资建议报告
- 投资评级
- 目标价格
- 投资逻辑
- 执行策略
```

## 分析模式选择

### 快速分析模式
**适用场景**: 日常监控、快速筛选
```bash
python main.py --company "公司名" --ticker "代码" --quick
```

**特点**:
- ⏱️ 执行时间: 2-3分钟
- 💰 成本: $0.05-0.10 (GPT-3.5)
- 📊 覆盖度: 核心指标和基础判断
- 🎯 适用性: 投资组合监控、初步筛选

**输出内容**:
- 基本面快速评估
- 技术面趋势判断
- 简化风险提示
- 明确投资建议

### 标准分析模式
**适用场景**: 常规投资决策
```bash
python main.py --company "公司名" --ticker "代码"
```

**特点**:
- ⏱️ 执行时间: 5-7分钟
- 💰 成本: $0.15-0.25 (GPT-3.5)
- 📊 覆盖度: 全面分析各个维度
- 🎯 适用性: 中等金额投资决策

**输出内容**:
- 详细的基本面分析
- 完整的技术面评估
- 全面的风险分析
- 具体的投资建议

### 深度分析模式
**适用场景**: 重要投资、深度研究
```bash
python main.py --company "公司名" --ticker "代码" --detailed
```

**特点**:
- ⏱️ 执行时间: 10-15分钟
- 💰 成本: $0.30-0.50 (GPT-3.5)
- 📊 覆盖度: 深度分析和行业对比
- 🎯 适用性: 大额投资、投资研究

**输出内容**:
- 深度基本面研究
- 详细技术分析
- 全面风险建模
- 综合投资策略

## 批量分析功能

### 投资组合分析
```bash
python main.py --batch portfolio.txt --mode portfolio
```

**功能**:
- 批量分析多只股票
- 组合风险评估
- 相关性分析
- 配置建议

### 行业对比分析
```bash
python main.py --batch sector_stocks.txt --mode compare
```

**功能**:
- 同行业股票对比
- 相对估值分析
- 行业排名
- 投资优选

### 热点追踪分析
```bash
python main.py --trending --sector "新能源汽车"
```

**功能**:
- 自动识别热点板块
- 热点股票筛选
- 趋势分析
- 机会挖掘

## 定制化功能

### 参数配置
```bash

python main.py --config custom_config.yaml
```

### 模板定制
```bash

python main.py --template my_template.md
```

### 指标选择
```bash
# 指定分析指标
python main.py --indicators "ROE,PEG,Beta" --company "公司名"
```

### 缓存机制
```bash

python main.py --use-cache --company "公司名"
```

### 并发处理
```bash
# 并发分析多个目标
python main.py --concurrent 3 --batch stocks.txt
```

```bash

python main.py --stream --company "公司名"
```
