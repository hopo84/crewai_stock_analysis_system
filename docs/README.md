## 📊 系统概览

### 核心特性
- 🤖 **多智能体协作** - 模拟专业投资团队分工
- 📈 **全面分析维度** - 基本面、技术面、风险等多角度分析
- ⚡ **实时数据支持** - 获取最新市场数据和信息
- 🛠️ **高度可配置** - 灵活的参数调整和功能定制
- 🌐 **多种接入方式** - CLI、API、Web等多种使用方式

### 智能体团队
| 智能体 | 职责 | 核心能力 |
|--------|------|----------|
| 市场研究分析师 | 市场调研 | 数据收集、趋势分析、行业比较 |
| 财务分析师 | 财务分析 | 报表分析、比率计算、盈利预测 |
| 技术分析师 | 技术分析 | 图表分析、指标计算、趋势判断 |
| 风险评估师 | 风险识别 | 风险建模、压力测试、风控建议 |
| 投资顾问 | 决策建议 | 综合评估、建议生成、策略制定 |

### 分析模式
| 模式 | 时间 | 成本 | 适用场景 |
|------|------|------|----------|
| 快速分析 | 2-3分钟 | $0.05-0.10 | 日常监控、快速筛选 |
| 标准分析 | 5-7分钟 | $0.15-0.25 | 常规投资决策 |
| 深度分析 | 10-15分钟 | $0.30-0.50 | 重要投资、深度研究 |
